# Cisco-Packet-Tracer-Network-Lab
A hands-on collection of 10 networking labs built using Cisco Packet Tracer, covering core networking concepts from basic LAN design to advanced ACL and firewall configurations.

## 📌 Overview

This project was completed during my time at **Eduzell L.L.P. (2024)** as my **first practical cybersecurity project**. It marks the beginning of my journey into understanding how networks are designed, configured, and secured — concepts that form the backbone of any cybersecurity career.

Every lab in this project was built and configured hands-on, with no pre-made templates. The goal was simple: understand how networks work before learning how to break or defend them.

| Tool | Purpose |

## 🧪 Labs

| # | Lab Title | Key Concepts |
|---|-----------|-------------|
| 01 | **Star Topology LAN Network** | Basic LAN design, switch connectivity, end-device communication |
| 02 | **Dual-Router Network** | Inter-network routing, individual switches per segment, router-to-router communication |
| 03 | **VLAN Configuration** | Virtual LAN setup, traffic segmentation, port assignment |
| 04 | **Inter-VLAN Routing — Router on a Stick** | Sub-interfaces, 802.1Q trunking, single-router inter-VLAN routing |
| 05 | **Inter-VLAN Routing — Layer 3 Switch** | Switched Virtual Interfaces (SVI), L3 switching, scalable VLAN routing |
| 06 | **Routing Protocol — RIP** | RIP v1/v2, dynamic routing, route advertisement |
| 07 | **Routing Protocol — OSPF** | Link-state routing, OSPF areas, neighbour adjacency |
| 08 | **ACL & Firewall Configuration** | Standard ACLs, basic traffic filtering, perimeter security simulation |
| 09 | **Extended ACL** | Source/destination filtering, port-based rules, granular traffic control |
| 10 | **Named ACL & Firewall Simulation** | Named ACLs, rule management, full firewall behaviour simulation |
