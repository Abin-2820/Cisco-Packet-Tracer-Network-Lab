# Cisco-Packet-Tracer-Network-Lab
A hands-on collection of 10 networking labs built using Cisco Packet Tracer, covering core networking concepts from basic LAN design to advanced ACL and firewall configurations.

## 📌 Overview

This project was completed during my time at **Eduzell L.L.P. (2024)** as my **first practical cybersecurity project**. It marks the beginning of my journey into understanding how networks are designed, configured, and secured — concepts that form the backbone of any cybersecurity career.

Every lab in this project was built and configured hands-on, with no pre-made templates. The goal was simple: understand how networks work before learning how to break or defend them.
